# 주안 플랜 — 교학 두뇌 서바이벌

주안권 남자부 창제회용 실시간 게임입니다. 진행자는 TV에 연결한 노트북으로 진행하고, 참가자는 각자 휴대폰으로 QR을 찍어 닉네임만 입력하고 참여합니다.

- 주소: https://wjdrldud2828-blip.github.io/juan-plan/
- 진행자: 첫 화면에서 **진행자로 방 만들기** → TV에 QR 표시 → `Space` 또는 `→`로 진행
- 참가자: QR 촬영 → 닉네임 입력

## 구성
| 게임 | 내용 |
|---|---|
| 1. 올인 베팅 퀴즈 | 분야·난이도만 보고 먼저 베팅 → 맞히면 획득, 틀리면 잃음 (마지막 문제 2배) |
| 2. 소수결 | A/B 중 적은 쪽을 고른 사람 +3 피스 |
| 3. 블라인드 심사 | 익명 한 줄 답안에 서로 투표, 1·2·3위 +5·+3·+2 |

## 문제 바꾸기
`src/data/content.ts` 한 파일만 수정하면 문제·질문·주제가 바뀝니다.

## 개발
```bash
npm install
npm run dev     # 로컬 실행
npm run build   # dist/ 생성
```
점수 계산과 권한 확인은 서버 함수(Supabase RPC)가 처리합니다.
